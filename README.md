# XKCD Search Microservices

**Микросервисная поисковая система** для комиксов [XKCD](https://xkcd.com) с веб-интерфейсом, Telegram-ботом.

Система состоит из 4 микросервисов (API Gateway, Update, Search, Words), взаимодействующих через gRPC. Использует событийное управление перестройкой индекса с помощью nats сервера. Включает REST API с JWT-аутентификацией, веб-интерфейс и Telegram-бота.

## Архитектура

Система построена на принципах **микросервисной архитектуры** с использованием **Clean Architecture** и разделением на слои: core, adapters, ports.

- **api** - REST API Gateway с JWT-аутентификацией, rate limiting и concurrency control (порт: 28080)
- **update** - Сервис загрузки и обновления комиксов из XKCD API (gRPC, порт: 28082)
- **search** - Сервис поиска с поддержкой поиска по БД и in-memory индексу (gRPC, порт: 28083)
- **words** - Сервис нормализации текста (gRPC, порт: 28081)
- **frontend** - Веб-интерфейс для поиска комиксов и администрирования системы (порт: 28084)
- **bot** - Telegram бот для поиска комиксов через мессенджер.

### Инфраструктура

- **PostgreSQL** - Хранение комиксов и ключевых слов (порт: 5432)
- **NATS** - Брокер сообщений для событийной архитектуры (порт: 4222)
- **PgAdmin** - Веб-интерфейс для PostgreSQL (порт: 18888)

## Основные возможности

### Веб-интерфейс (frontend)

- **Страница поиска** (`/search`) - поиск комиксов по ключевым словам с отображением результатов в виде карточек
- **Админ-панель** (`/admin`) - управление базой данных:
  - Авторизация через JWT
  - Просмотр статистики (количество комиксов, слов)
  - Просмотр статуса обновления
  - Запуск обновления базы данных
  - Очистка базы данных

## Технологический стек

- **Backend** - Go, gRPC, Protocol Buffers, REST API
- **База данных** - PostgreSQL
- **Брокер сообщений** - NATS
- **Frontend** - JavaScript (vanilla), HTML/CSS
- **DevOps** - Docker, Docker Compose, Makefile
- **Аутентификация** - JWT
- **Стемминг** - Snowball
- **Логирование** - slog (структурированное)
- **Конфигурация** - cleanenv

### Запуск

````bash
# Клонирование репозитория
git clone
cd xkcd-search

# Запуск всех сервисов
make up

# Остановить сервисы
make down

# Запустить интеграционные тесты
make test
### Доступ к сервисам

- **Frontend (веб-интерфейс)**: http://localhost:28084
- **API Gateway**: http://localhost:28080
- **Words Service**: http://localhost:28081
- **Update Service**: http://localhost:28082
- **Search Service**: http://localhost:28083
- **PostgreSQL**: localhost:5432
- **PgAdmin**: http://localhost:18888
- **NATS**: localhost:4222

### Использование веб-интерфейса

1. Откройте http://localhost:28084 в браузере
2. На главной странице введите поисковый запрос и нажмите "Найти"
3. Для доступа к админ-панели нажмите кнопку "⚙️ Админ-панель" в правом нижнем углу
4. Войдите используя учетные данные (по умолчанию: `admin` / `password`)

### Настройка Telegram бота

1. Создайте бота в Telegram и получите токен.
2. Установите токен бота перед запуском:

   ```bash
   # Windows (PowerShell)
   $env:BOT_TOKEN="ваш_токен_бота"

   # Linux/Mac
   export BOT_TOKEN="ваш_токен_бота"
````

3. Запустите систему:

   ```bash
   make up
   ```

4. Найдите вашего бота в Telegram и отправьте команду `/start`

**Доступные команды бота:**

- `/start` - приветствие и инструкция
- `/search <фраза>` - поиск комиксов по ключевым словам
- `/help` - справка по использованию
